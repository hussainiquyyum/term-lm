# Contributing to TERM-LM

TERM-LM is maintained by Husaini Holding.

- Open an issue for a reproducible bug (version, OS, shortest steps, expected vs actual).
- For features or larger changes, open a discussion first.
- Run `just check` before opening a pull request, and follow the architecture rules in `AGENTS.md`.
- Use lowercase conventional commit subjects (`fix: handle pane focus`).

By contributing you agree your work is licensed under Apache-2.0.
